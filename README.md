# yardnote

Yard HTML/Markdown note fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/yardnote/

## Install / run

```bash
git clone https://github.com/theworker02/yardnote.git
cd yardnote
node src/cli.js
node --test
```
